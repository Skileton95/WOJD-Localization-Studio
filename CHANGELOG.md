# Changelog

## 0.1.26

- Анализ открытых файлов: разные непустые переводы одного source, один перевод у разных оригиналов и повторяющиеся китайские фрагменты.
- Просмотр всех мест использования и вариантов; применение выбранного перевода ко всем идентичным исходникам без автоматического сохранения.
- Фильтр «Несогласованные»; регрессионные проверки межфайловых конфликтов и загрузки интерфейса.

## 0.1.25

- Сворачиваемая панель Namespace: поиск, точная фильтрация, счётчики всего/переведено/без перевода/QA и процент готовности.
- Контекстное меню Namespace: перейти, сбросить фильтр, экспортировать строки в NDJSON.
- Счётчики включают несохранённые переводы; поддержан пустой Namespace.
- Проверки используют изолированное workspace-хранилище.

## 0.1.24

- Вкладки файлов: красное закрытие, средняя кнопка мыши, закрепление, Ctrl+Tab / Ctrl+Shift+Tab и Ctrl+W.
- Сохранение порядка вкладок, закрепления, размеров окна и ширины/видимости панели файлов (по умолчанию 300 px).
- Подсветка активного файла; защита от повторной одновременной загрузки.
- Исправлено сохранение NDJSON в Windows: поток закрывается до замены оригинала.
- Регрессионные проверки в CI; предыдущие GitHub Releases сохраняются для восстановления.
