# WOJD Localization Studio

Минималистичный Windows-редактор файлов русификатора.

## Текущая версия

**0.1.34**

## Возможности редактора

- настоящий multi-file режим: открытые файлы остаются в памяти и переключаются без потери изменений;
- восстановление открытых файлов, папок, активного файла и выбранной строки после перезапуска;
- recovery-черновик несохранённых переводов в `%LocalAppData%`, не изменяющий оригинальные файлы;
- автоматическое восстановление черновика после сбоя или перезапуска во время обновления;
- активный файл помечается в дереве маркером `●`;
- открытие нескольких `.ndjson` / `.jsonl` файлов за один раз;
- открытие папки и расширенное дерево файлов с хорошо читаемым количеством строк напротив каждого файла;
- красный `×` справа от каждого файла для быстрого закрытия;
- таблица `Namespace / Ключ / Оригинал / Перевод / QA / Статус` с множественным выделением строк;
- поиск по namespace, ключу, оригиналу и переводу;
- `Ctrl+Shift+F` — поиск сразу по всем открытым файлам;
- отдельное окно результатов поиска по проекту с переходом к файлу и строке;
- история последних 20 запросов;
- режимы поиска: учёт регистра, точное совпадение и regex;
- явная пометка строк, где `source` действительно пуст в исходном файле;
- QA-проверка сохранности плейсхолдеров `{0}`, `%s` и подобных;
- QA-проверка тегов `<...>` и количества переносов строк;
- фильтр `Ошибки`, счётчик проблемных строк и подсветка QA-ошибок;
- описание найденной QA-проблемы в таблице и нижнем редакторе;
- кликабельные фильтры `Все / Переведено / Без перевода / Изменено` без отдельного выпадающего списка;
- редактирование перевода в отдельной панели;
- переход между строками;
- статистика перевода;
- сохранение с резервной копией;
- `*` у изменённых файлов в дереве;
- `Ctrl+S` сохраняет текущий файл, `Ctrl+Shift+S` — все изменённые файлы;
- закрытие отдельного файла через контекстное меню дерева;
- отдельная история Undo/Redo для каждого открытого файла;
- предупреждение со списком несохранённых файлов при закрытии программы;
- поддержка поля `translated` в NDJSON-файлах;
- фоновая загрузка и разбор больших файлов без блокировки интерфейса;
- пакетное обновление таблицы и recycling-виртуализация;
- уменьшенное потребление памяти при работе с NDJSON;
- отложенный поиск и быстрый пересчёт статистики;
- ручная кнопка `Проверить обновления` с явным результатом проверки;
- обновления через стабильный `update.json` без зависимости от лимита GitHub API;
- диагностический `update.log` для проверки работы автообновления;
- self-contained Windows-сборка: отдельная установка .NET Desktop Runtime не требуется;
- единый фирменный стиль внутренних всплывающих окон и окна обновления;
- фильтрация по Namespace нажатием на его название в таблице;
- фильтр Namespace отображается отдельной строкой перед таблицей и снимается маленьким `×`;
- `Ctrl+F` сразу переводит курсор в поиск;
- `Ctrl+H` открывает компактную панель «Найти и заменить»;
- замена в текущей строке и массовая замена в текущем файле/Namespace;
- массовые действия через правый клик: `Оригинал → перевод`, очистка перевода, экспорт выбранных;
- экспорт в NDJSON выбранных, непереведённых и QA-ошибок;
- сравнение текущего файла со старой версией по `Namespace + Key`;
- статусы сравнения `Добавлено / Удалено / Изменён оригинал / Изменён перевод` и фильтр по ним;
- безопасный перенос переводов из старой версии в новую;
- строки с изменённым китайским оригиналом явно предупреждаются и автоматически не переносятся;
- `F6 / Shift+F6` — следующая/предыдущая непереведённая строка;
- `Ctrl+G` — переход по номеру строки, ключу или `Namespace:Key`;
- `Ctrl+Z / Ctrl+Y` — отмена и повтор изменений перевода;
- меню `Правка` с командами Undo/Redo и горячими клавишами;
- компактная сворачиваемая панель файлов с минималистичной центральной стрелкой;
- меню `Файл / Правка / Справка` вынесено отдельной строкой над логотипом, как в классических desktop-программах;
- строка статистики расположена над поиском;
- оригинальный текст отображается как полностью нередактируемый блок;
- исправлена блокировка ZIP-файла при проверке SHA-256 во время обновления.

## Обновления

Опубликованные сборки обновляются через GitHub Releases без ручного скачивания архивов.

- при запуске программа проверяет новую версию;
- пока программа открыта, проверка выполняется каждую 1 минуту;
- опубликованная сборка регистрирует пользовательскую задачу Windows, которая проверяет обновления каждую 1 минуту, даже когда редактор закрыт;
- при доступном обновлении показывается окно с кнопками `Обновиться` и `Позже`;
- после нажатия `Обновиться` внизу главного окна показываются статус и прогресс загрузки;
- обновление скачивается во временную папку, проверяется, заменяет файлы программы и автоматически запускает редактор снова.

GitHub Actions автоматически собирает новую Windows-сборку и создаёт GitHub Release при каждом изменении `main`. Для каждой новой публикации нужно увеличить `<Version>` в проектах приложения и updater.

## Сборка

Требуется .NET 8 SDK.

```powershell
dotnet build WOJD.LocalizationStudio.sln
```

Запуск из исходников:

```powershell
dotnet run --project .\src\WOJD.LocalizationStudio\WOJD.LocalizationStudio.csproj
```

## Публикация локально

```powershell
.\publish.bat
```
