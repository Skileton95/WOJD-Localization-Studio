# WOJD Localization Studio

Windows-редактор файлов русификатора World of Jade Dynasty / Zhu Xian World.

## Текущая версия

**0.1.59**

## Возможности редактора

- multi-file режим: открытые файлы остаются в памяти и переключаются без потери изменений;
- восстановление открытых файлов, папок, активного файла и выбранной строки после перезапуска;
- recovery-черновик несохранённых переводов в `%LocalAppData%`, не изменяющий оригинальные файлы;
- открытие `.ndjson` / `.jsonl` файлов и целых папок;
- поиск по namespace, ключу, оригиналу и переводу, включая поиск по проекту;
- фильтры `Все / Переведено / Без перевода / Изменено / Ошибки` и фильтр Namespace;
- быстрые QA-фильтры `Теги / Плейсхолдеры / Переносы`;
- встроенный `FAQ и справка` в меню `Справка`, открываемый также клавишей `F1`;
- FAQ охватывает все основные кнопки, окна, механики, горячие клавиши и типичные сценарии; внутри есть поиск и категории.

### Стабильный рабочий редактор

- нижний редактор вынесен в отдельный статический XAML-компонент вместо набора динамически дорисовываемых панелей;
- `GridSplitter` позволяет менять высоту редактора мышкой;
- высота, свёрнутое состояние, размер шрифта, перенос строк и видимость основных колонок запоминаются;
- редактор можно свернуть и развернуть без потери текста;
- настройки интерфейса и ИИ доступны из окна настроек редактора;
- старые конфликтующие UI-enhancement модули нижней панели удалены.

### QA и защита структуры

- проверка плейсхолдеров `{0}`, `%s`, `${...}` и подобных;
- проверка тегов `<...>` и переносов строк;
- индикаторы `✕` ошибка структуры, `⚠` предупреждение, `—` проверить невозможно, `✓` структура корректна;
- строки без Original явно показываются как непроверяемые;
- структурный diff показывает количество тегов, плейсхолдеров и переносов в Original и Translation;
- точный список отсутствующих и лишних токенов и предупреждение о нарушенном порядке;
- цветной предпросмотр тегов/плейсхолдеров: технические токены отделены от обычного текста, проблемные выделяются;
- защита тегов и плейсхолдеров при Backspace/Delete/Cut и предупреждение при опасной вставке;
- безопасное восстановление однозначно повреждённой структуры по Original;
- QA-профили по маскам Namespace/Key с ограничениями длины и переносов;
- глоссарий интегрирован в QA: обязательный термин из Original должен иметь заданный русский вариант.

### Автоисправление и большие файлы

- безопасное автоисправление текущей строки;
- массовое автоисправление всего файла с предпросмотром;
- анализ массового автоисправления выполняется в фоне с прогрессом и отменой;
- защитный снимок создаётся перед массовым применением;
- пакетный Undo/Redo для массовых операций;
- рассчитано на файлы с сотнями тысяч строк без полного анализа на каждый ввод символа.

### Translation Memory и согласованность

- встроенная Translation Memory строит индекс текущего файла в фоне;
- показывает точные и похожие Original с уже существующими переводами;
- предложение TM можно применить двойным кликом или кнопкой;
- аудит согласованности находит один и тот же Original с разными русскими переводами;
- можно безопасно унифицировать группу самым частым вариантом с предварительным снимком;
- встроенный глоссарий `Source → Target`, обязательные и рекомендуемые термины.

### Проверка перевода

- ручные статусы `Не проверено / Проверено / Требует правки / Пропустить`;
- статусы хранятся отдельно от игрового NDJSON;
- `Проверено` автоматически сбрасывается после изменения перевода;
- workflow `✓ и дальше / ⚠ и дальше` для последовательной проверки;
- история изменений выбранной строки с восстановлением предыдущего текста;
- история операций проекта хранит ручные и массовые действия;
- снимки состояния переводов всего файла и восстановление снимка;
- хранение последних 10 снимков на файл.

### ИИ-проверка

- проверка текущей строки через OpenAI Responses API только через предпросмотр;
- пакетная проверка выделенных/проблемных строк;
- ответы ИИ со сломанными тегами или плейсхолдерами отклоняются;
- настраиваемые concurrency, retries и максимальный размер пакета;
- перед пакетным запуском показывается примерная оценка input/output токенов;
- ориентировочная стоимость рассчитывается только если пользователь сам указал актуальные цены выбранной модели;
- перед пакетным применением создаётся снимок;
- API key не сохраняется в проекте: используется текущий сеанс или `OPENAI_API_KEY`;
- модель настраивается пользователем, по умолчанию `gpt-5.6-sol`.

### Работа с файлами

- безопасное сохранение через уникальный временный файл;
- полная проверка временного NDJSON до замены оригинала;
- сериализация параллельных сохранений одного файла;
- резервные копии перед сохранением и массовыми операциями;
- мониторинг внешних изменений открытого файла;
- если файл изменён другой программой, редактор предлагает `Сравнить / Перезагрузить / Сохранить поверх / Игнорировать`;
- сравнение показывает различия перевода между памятью редактора и версией на диске;
- сравнение текущего файла со старой версией по `Namespace + Key` и безопасный перенос переводов;
- экспорт выбранных, непереведённых и QA-ошибок в NDJSON.

### Горячие клавиши

- `Ctrl+F` — поиск;
- `Ctrl+H` — найти и заменить;
- `Ctrl+G` — переход к строке/ключу;
- `Ctrl+S` / `Ctrl+Shift+S` — сохранить / сохранить всё;
- `Ctrl+Z` / `Ctrl+Y` — Undo/Redo, включая последнюю совместимую пакетную операцию;
- `F6 / Shift+F6` — следующая/предыдущая непереведённая;
- `F7 / Shift+F7` — следующая/предыдущая структурная QA-ошибка;
- `F1` — полный встроенный FAQ;
- `Ctrl+F` внутри FAQ — поиск по справке.

## Регрессионные тесты

В репозитории есть отдельный тестовый проект и CI для pull request. Проверяются критические сценарии:

- обнаружение отсутствующих тегов и плейсхолдеров;
- восстановление повреждённого тега;
- сохранение структуры после автоисправления;
- точное совпадение Translation Memory;
- поиск разных переводов одного Original;
- безопасный round-trip сохранения NDJSON без оставшегося `.save.tmp`.

## Обновления

Опубликованные сборки обновляются через GitHub Releases:

- при запуске программа проверяет новую версию;
- пока программа открыта, проверка выполняется периодически;
- обновление скачивается во временную папку, проверяется и заменяет файлы программы;
- после обновления редактор автоматически запускается снова.

GitHub Actions собирает Windows self-contained release при изменении `main`. Отдельная установка .NET Desktop Runtime не требуется.

## Сборка

Требуется .NET 8 SDK.

```powershell
dotnet build WOJD.LocalizationStudio.sln
```

Запуск:

```powershell
dotnet run --project .\src\WOJD.LocalizationStudio\WOJD.LocalizationStudio.csproj
```

Тесты:

```powershell
dotnet test .\tests\WOJD.LocalizationStudio.Tests\WOJD.LocalizationStudio.Tests.csproj -c Release
```

Публикация локально:

```powershell
.\publish.bat
```
