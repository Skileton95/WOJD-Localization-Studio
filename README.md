# WOJD Localization Studio

Минималистичный Windows-редактор файлов русификатора.

## Текущая версия

**0.1.4**

## Возможности редактора

- открытие `.ndjson` / `.jsonl` файлов;
- открытие папки и дерево файлов;
- таблица `Ключ / Оригинал / Перевод / Статус`;
- поиск по ключу, оригиналу и переводу;
- фильтры `Все / Без перевода / Переведено / Изменено`;
- редактирование перевода в отдельной панели;
- переход между строками;
- статистика и счётчик символов;
- сохранение с резервной копией;
- предупреждение о несохранённых изменениях.

## Обновления

Опубликованные сборки обновляются через GitHub Releases без ручного скачивания архивов.

- при запуске программа проверяет новую версию;
- пока программа открыта, проверка выполняется каждые 15 минут;
- опубликованная сборка регистрирует пользовательскую задачу Windows, которая проверяет обновления каждые 15 минут, даже когда редактор закрыт;
- обновление скачивается во временную папку, заменяет файлы программы и при обновлении из открытого редактора автоматически запускает его снова.

GitHub Actions автоматически собирает новую Windows-сборку и создаёт GitHub Release при каждом изменении `main`. Для каждой новой публикации нужно увеличить `<Version>` в проектах приложения и updater.

## Сборка

Требуется .NET 8 SDK.

```powershell
dotnet build WOJD.LocalizationStudio.sln
```

Запуск из исходников:

```powershell
dotnet run --project .\src\WOJD.LocalizationStudio\WOJD.LocalizationStudio.csproj
```

## Публикация локально

```powershell
.\publish.bat
```
