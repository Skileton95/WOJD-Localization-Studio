# WOJD Localization Studio

Windows-редактор файлов русификатора World of Jade Dynasty / Zhu Xian World.

## Текущая версия

**0.2.11**

## Связанные строки и производительность 0.2.11

Версия 0.2.11 улучшает работу с родственными ключами и большими файлами.

- правая панель показывает связанные строки текущего ключа: одно семейство ключа, соседние числовые варианты и строки с тем же Original;
- для связанных строк доступны быстрый переход и сравнение;
- связанные семейства визуально отделяются прямо в основном списке без тяжёлой WPF-группировки и без отключения виртуализации;
- окно **«Сравнение строк»** показывает Original и Translation двух строк рядом и подсвечивает различающиеся фрагменты;
- связи строятся через индекс документа, поэтому выбор строки больше не запускает полный проход по сотням тысяч записей;
- позиция текущей строки вычисляется через индексированное хранилище за O(1), а не линейным поиском;
- DataGrid использует recycling/column virtualization;
- обычный клик по строке больше не вызывает лишний `ScrollIntoView`;
- добавлены регрессионные тесты семейств ключей, связанных строк, визуальных групп и индексированных позиций.

## Тест автообновления 0.2.10

Версия 0.2.10 — минимальный контрольный релиз, которым был подтверждён реальный сценарий автообновления с 0.2.9 через кнопку **«Обновить»**.

## Исправление обновления 0.2.9

Версия 0.2.9 исправляет сценарий, при котором обновление успешно скачивалось, приложение закрывалось, но установка не продолжалась.

- updater заранее копируется в независимую staging-область рядом с установленной программой **до** закрытия приложения;
- пакет обновления хранится в локальной `.update`-области приложения вместо `%TEMP%`;
- ZIP применяется потоково без полной распаковки пакета на системный диск;
- замена файлов выполняется с повторными попытками для кратковременных блокировок Windows;
- после установки проверяется `version.txt`;
- таймаут ожидания закрытия основной программы больше не игнорируется;
- при ошибке updater показывает сообщение, пишет подробности в `update.log` и пытается снова запустить установленную программу;
- добавлен end-to-end smoke-test настоящего `WOJD-Localization-Studio.Updater.exe`: staging → применение тестового ZIP → проверка версии и файлов;
- release workflow не публикует новую версию, если updater smoke-test не прошёл.

## Интерфейс 0.2

Ветка 0.2 использует новую оболочку с постоянной левой навигацией и отдельными рабочими разделами:

- **Проект** — открытые файлы, папки и переход к текущему документу;
- **Перевод** — основной список строк и редактор `Original → Translation`;
- **Поиск** — поиск по открытому проекту;
- **Проверка** — отдельный QA-центр;
- **Статистика** — состояние перевода и проблем текущего файла;
- **Настройки** — параметры редактора и рабочей области;
- **О программе** и встроенная справка.

### Улучшения 0.2.8

- runtime smoke-test реально создаёт `ShellWindow` на STA-потоке и ловит ошибки XAML/WPF-привязок до релиза;

- пустой декоративный игровой preview скрыт: правая колонка используется для реального контекста строки;
- контекст показывает одинаковые Original, варианты их переводов, связанные ключи и QA;
- QA-центр разделяет проблемы на: нет Original, теги, плейсхолдеры, переносы, глоссарий, одинаковый Original с разными переводами, совпадение с Original и подозрительные строки/QA-профили;
- статистика показывает отдельные типы QA и Namespace с наибольшим числом непереведённых строк;
- в новой оболочке доступны `Ctrl+H` (найти/заменить), `Ctrl+G` (переход к строке/ключу), Undo/Redo и экспорт текущей строки, непереведённых и QA-проблем.

## QA и структура

- проверка тегов `<...>`;
- проверка плейсхолдеров `{0}`, `%s`, `${...}` и подобных;
- проверка переносов строк;
- понятные состояния `✓ / ✕ / ⚠ / —`;
- корректное состояние для строк без Original;
- структурный diff и список отсутствующих/лишних токенов;
- защита тегов и плейсхолдеров при Backspace/Delete/Cut и опасной вставке;
- безопасное восстановление структуры по Original;
- QA-профили по Namespace/Key;
- глоссарий участвует в проверке терминологии;
- контроль согласованности одинакового Original.

## Редактирование и автоисправление

- безопасное редактирование перевода без обновления модели на каждый символ;
- история ручных и программных изменений строки;
- автоисправление текущей строки;
- автоисправление **только текущего активного файла** с предпросмотром;
- фоновый анализ больших файлов с прогрессом и отменой;
- защитные снимки перед массовыми операциями;
- Undo/Redo;
- поиск и замена;
- переход к строке или ключу.

## Согласованность и глоссарий

- поиск одинакового Original с разными переводами;
- безопасная унификация группы;
- встроенный глоссарий `Source → Target`;
- обязательные и рекомендуемые термины;
- Translation Memory и индекс уже существующих переводов остаются внутренними сервисами редактора.

## Работа с файлами

- multi-file режим;
- открытие `.ndjson` / `.jsonl` и папок;
- восстановление рабочего пространства после перезапуска;
- recovery-черновики несохранённых переводов;
- безопасное сохранение через временный файл;
- проверка временного NDJSON перед заменой оригинала;
- резервные копии;
- мониторинг внешних изменений файла;
- `Сравнить / Перезагрузить / Сохранить поверх / Игнорировать` при изменении файла другой программой;
- сравнение с предыдущей версией и безопасный перенос переводов;
- экспорт текущей строки, непереведённых и QA-проблем.

## Горячие клавиши

- `Ctrl+O` — открыть файл;
- `Ctrl+Shift+O` — открыть папку;
- `Ctrl+S` / `Ctrl+Shift+S` — сохранить / сохранить всё;
- `Ctrl+F` — поиск в текущем файле;
- `Ctrl+Shift+F` — поиск по проекту;
- `Ctrl+H` — найти и заменить;
- `Ctrl+G` — перейти к строке или ключу;
- `Ctrl+Z` / `Ctrl+Y` — Undo / Redo;
- `F6 / Shift+F6` — следующая / предыдущая непереведённая;
- `F7 / Shift+F7` — следующая / предыдущая QA-проблема;
- `F1` — FAQ и справка.

## Тесты

Регрессионные тесты проверяют структуру тегов и плейсхолдеров, восстановление, автоисправление, Translation Memory, согласованность и безопасный NDJSON-save. Начиная с 0.2.8 также выполняется WPF smoke-test запуска новой оболочки и end-to-end проверка сохранения файла. В 0.2.9 добавлен отдельный end-to-end тест реального updater.exe. В 0.2.11 добавлены проверки индекса связанных ключей и индексированного хранения строк.

```powershell
dotnet test .\tests\WOJD.LocalizationStudio.Tests\WOJD.LocalizationStudio.Tests.csproj -c Release
```

## Сборка

Требуется .NET 8 SDK.

```powershell
dotnet build WOJD.LocalizationStudio.sln
```

Запуск:

```powershell
dotnet run --project .\src\WOJD.LocalizationStudio\WOJD.LocalizationStudio.csproj
```

GitHub Actions публикует Windows self-contained сборку при изменении `main`. Отдельная установка .NET Desktop Runtime не требуется.
