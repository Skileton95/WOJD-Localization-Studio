# WOJD Localization Studio v0.2.1

Рабочий прототип редактора русификатора Zhu Xian World на WPF / .NET 8.

## Что реализовано в v0.2.1

### 1. Работа с файлами русификатора
- Поддержка `ru.ndjson` и `ru.fmtstring.ndjson`.
- Можно открыть сразу несколько `.ndjson` файлов.
- Открытые файлы отображаются слева и переключаются одним кликом.
- Поддерживается реальная WOJD-структура:
  - `namespace`
  - `key`
  - `source`
  - `translated`
- При сохранении меняется только поле перевода; остальные поля записи сохраняются.
- Запись идёт через временный файл, затем атомарно заменяет исходный файл.
- Автоматические резервные копии в этой версии НЕ создаются.

### 2. Редактор строки
- Китайский оригинал доступен только для чтения.
- Русский перевод редактируется справа.
- `Ctrl+O` — открыть файл(ы).
- `Ctrl+S` — сохранить текущий файл.
- Кнопка `Сохранить всё` сохраняет все изменённые открытые файлы.

### 3. Поиск
Поиск ограничен четырьмя нужными областями:
- `Key`
- `Namespace`
- китайский оригинал
- русский перевод

В выпадающем списке можно выбрать конкретную область или `Все поля`.

### 4. Проверка технических элементов
Проверка выполняется при загрузке, во время редактирования строки и вручную кнопкой `Проверка`.

Проверяются:
- `{0}`, `{1}` и другие нумерованные плейсхолдеры;
- `%s`, `%d`, включая позиционные формы вроде `%1$s`;
- переносы строки `\n`;
- XML/HTML-подобные теги `<tag>`, `</tag>` и теги с атрибутами.

Если в русском переводе потерян или добавлен технический элемент, строка получает статус `Ошибка`, а справа показывается точная причина.

Пустые, ещё не переведённые строки не считаются ошибкой проверки.

## Сборка

Требуется .NET 8 SDK для Windows.

Запустите:

`build.bat`

Готовый exe после обычной сборки:

`src\WOJD.LocalizationStudio\bin\Release\net8.0-windows\WOJD.LocalizationStudio.exe`

Для автономной single-file сборки:

`publish-portable.bat`

Результат:

`publish\win-x64\WOJD.LocalizationStudio.exe`

## Пока не реализовано
- резервные копии;
- сравнение старой и новой версии файлов;
- AI-перевод;
- глоссарий.

## Обновление через GitHub

Репозиторий: `Skileton95/WOJD-Localization-Studio`.

После однократного клонирования проекта для следующих обновлений достаточно запустить:

`update.bat`

Скрипт:
- закрывает запущенный `WOJD.LocalizationStudio.exe`;
- проверяет, что в исходниках нет несохранённых локальных изменений;
- выполняет `git pull --ff-only origin main`;
- восстанавливает зависимости;
- собирает Release-версию.

Готовый EXE находится в:

`src\WOJD.LocalizationStudio\bin\Release\net8.0-windows\WOJD.LocalizationStudio.exe`

## v0.2.7
- В редакторе появился блок точных совпадений оригинала.
- Совпадение считается только при полном равенстве поля `source` через `StringComparison.Ordinal`.
- Частичные, похожие, нормализованные и отличающиеся регистром/пробелами строки не считаются совпадениями.
- Показывается количество строк с идентичным оригиналом.
- Если у одинакового оригинала есть разные непустые переводы, показывается предупреждение о конфликте.
- Кнопка «Применить ко всем точным совпадениям» переносит текущий перевод только на строки с 100% идентичным `source` в активном файле.
