# Проверка v0.2.15

Каждый релиз v0.1.24–v0.2.15 имеет отдельный коммит main, совпадающие версии приложения/updater и запись changelog. К следующей версии переходили после успешного Actions предыдущего коммита. [История сборок](https://github.com/Skileton95/WOJD-Localization-Studio/actions/workflows/release.yml).

## Автоматические проверки

- 127 утверждений: multi-file, вкладки/закрепление, независимый и общий Undo/Redo, Namespace/фильтры/замена, старый workspace, recovery, резервные копии, внешние изменения, кодировки, неизвестные поля, физические строки и переносы.
- Сценарий проекта: CN/EN/RU → импорт → Undo/Redo → глоссарий/QA → ревью → UTF-16-сохранение → SQLite/поиск → переход к защищённому исходнику → ZIP. Хэши CN/EN неизменны; NDJSON внутри ZIP совпадает побайтно с сохранённым RU.
- Загрузка основного WPF-окна и 26 окон рабочих процессов в изолированной сессии; основное окно дополнительно проверено по изображению. Светлый стиль, панель файлов 300 px, красные крестики и чёрные счётчики сохранены.
- Готовое self-contained приложение запускается с `--self-check`: проверяет NDJSON, неизвестные поля, отсутствие последнего переноса, QA, нативную SQLite-зависимость и версию. Использует синтетический файл в изолированном workspace.
- Git-проверка использует временный локальный репозиторий: выбранный коммит оставляет посторонние staged-файлы вне коммита.

## Как воспроизвести

```powershell
dotnet build WOJD.LocalizationStudio.sln -c Release
dotnet run --project tests/WOJD.LocalizationStudio.Tests -c Release
dotnet run --project tests/WOJD.LocalizationStudio.Tests -c Release -- --perf-index 100000
dotnet run --project tests/WOJD.LocalizationStudio.Tests -c Release -- --perf-vm 1000000
$env:WOJD_WORKSPACE_DIRECTORY = Join-Path $env:TEMP 'wojd-self-check'
& '.\WOJD-Localization-Studio.exe' --self-check
```

Самопроверка записывает `self-check.json` (при ошибке `self-check-error.log`) в выбранный workspace. Диагностика доступна через меню справки.

## Практические ограничения

Образцы реальных файлов и проверенный бинарный конвертер WOJD не предоставлены. Проверены сохранность синтетических NDJSON, заявленные правила QA и интерфейс; работоспособность перевода в игре не подтверждена. Нативное чтение/запись бинарных locres/fmtstring, полный разбор грамматики Unreal и сетевой обмен совместной работы требуют отдельной спецификации. Их ограничения видны в интерфейсе и документации; исходные бинарные файлы не преобразуются предположениями.
