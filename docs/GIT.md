# Git в редакторе

Панель работает с существующей локальной рабочей копией и установленным Git. Статус читается в стабильном [porcelain v1 с NUL-разделителями](https://git-scm.com/docs/git-status), в том числе для Unicode и переименований. Пути передаются как отдельные аргументы с literal pathspec, shell не используется.

Коммит требует выбора файлов и просмотра сохранённых изменений; правки в памяти блокируют коммит. Применяется [git commit --only](https://git-scm.com/docs/git-commit), чтобы staged-изменения других файлов не попали в коммит. Обычные правила Git, хуки и локальное имя/почта остаются в силе. Ошибки сообщаются пользователю; при неудаче стадия может остаться для ручного просмотра. Ветки переключаются без force, reset или автоматического stash.

История выбранной строки использует её физический номер в сохранённом файле. После переключения ветки внешний контроль редактора предложит сравнить/перезагрузить документы. Сетевые операции выполняются вне этой панели.
