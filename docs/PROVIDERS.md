# Провайдеры форматов

ILocalizationFormatProvider возвращает единый LocalizationDocument и описывает поддерживаемые расширения и возможности. FormatProviderRegistry выбирает NDJSON по расширению, а происхождение fmtstring NDJSON — только из явно назначенного источника проекта. Document.ProviderId сохраняет выбор для записи. Неизвестный Id, несовместимое расширение и отсутствие CanWrite блокируют запись.

NDJSON-провайдер сохраняет исходные поля и алиасы. Провайдер fmtstring NDJSON представляет текстовый экспорт того же формата; он не объявляет неизвестный бинарный формат текстовым. BinarySourceProvider предоставляет ограничения и направляет к внешнему проверенному инструменту. Реестр не загружает внешние сборки автоматически; новый кодек подключается через проверенную реализацию интерфейса с тестами образцов, сохранности и обратной совместимости.

Исходные игровые файлы не заменяются кэшем SQLite или JSON metadata редактора. Нативный locres/fmtstring кодек остаётся отдельной задачей, требующей спецификации/инструмента и реальных образцов.
